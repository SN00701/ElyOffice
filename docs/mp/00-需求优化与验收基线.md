# MPelyoffice 需求优化与验收基线

版本：0.1（基线）
日期：2026-10-20
状态：已与需求方确认，作为后续所有设计与验收的唯一依据
适用范围：Windows 10 1809+ / Windows 11，x86_64

---

## 1. 原始需求（未经消歧）

> 分析 https://github.com/ELY-Open-Source/ElyOffice 。该项目的作者把每个软件分开打包。
> 需要做一个 Windows 64 位软件，叫做 MPelyoffice，类似 WPS 的界面和相关功能，
> 能够只安装本软件就实现所有软件安装，并且只需要启动本软件就可以进行相关文件的打开和编辑。
> 优化我的问题后进行计划开发；按第一性原理开发；开发完成后做对抗式审查。

## 2. 需求消歧：原始表述 → 可验收条目

原始需求包含 5 处歧义或缺失，每一处都可能让"做完"与"做对"完全背离。下表是消歧结果，
后文所有文档、代码与测试均以右列为准。

| 编号 | 原始表述 | 歧义点 | 消歧后的可验收需求 | 验收方式 |
| --- | --- | --- | --- | --- |
| R1 | "只安装本软件就实现所有软件安装" | 是否允许依赖用户已有环境（已装 Office / LibreOffice / .NET / Java）？ | **零外部前置依赖**：安装后目标机不需预装任何 Office、LibreOffice、.NET、Java、Python、Node。目标机仅需 Windows 10 1809+ / Win11 x64 | 干净虚拟机（仅系统）安装单个包后，6 类文件全部可打开可编辑 |
| R2 | "只需要启动本软件就可以进行相关文件的打开和编辑" | 是"1 个安装包"还是"1 个进程"？二者是不同工程量 | **1 个安装包 + 1 个启动器 + 1 个主窗口**：文字/表格/演示/PDF/Markdown/文本在同一窗口的标签页中混排打开；同一 exe 可另起第二个顶层窗口 | 双击任意受支持文件 → 仅启动 1 个进程 → 文件出现在已有窗口的新标签；同一 exe 可再开独立窗口 |
| R3 | "类似 WPS 的界面和相关功能" | 相似到什么程度？像素级照抄？ | **信息架构同构、视觉自有**：功能区（Ribbon）+ 文档标签栏 + 开始页 + 左侧导航 + 状态栏 + 统一设计令牌 + 中英双语；走 Ely GPUI Components 设计体系，**不复制 WPS 像素、不泄露上游 Office 界面** | 界面评审 + 组件库一致性检查 + 无上游对话框泄露 |
| R4 | 未提及 | 能否夺取文件默认关联？ | **绝不夺取默认**。仅注册 ProgID + `OpenWithProgids` + `RegisteredApplications` + `ShellNew`；应用内提供"设为默认"按钮，**跳转系统设置**由用户完成 | 安装后 `HKCU\...\FileExts\<ext>\UserChoice` 不变；"打开方式"菜单出现 MPelyoffice |
| R5 | 未提及 | 编辑保真度目标？是否承诺 Word/Excel 全功能？ | **按格式公布支持矩阵**（原生编辑 / 转换后编辑 / 仅查看 / 不支持），只承诺矩阵内能力；不做宏执行、协作、云服务 | 发布 `docs/mp/06-格式支持矩阵与许可合规表.md`，产品内状态栏如实显示当前能力 |

## 3. 目标用户与典型场景

面向处理本地文件的个人、开发者与小团队。**不需要注册账号，不需要联网。**

| 场景 | 用户动作 | 完成条件 |
| --- | --- | --- |
| 审阅合同 | 双击 DOCX → 改条款 → 加批注 → 保存 → 导出 PDF | 原表格、编号、页眉页脚、修订记录按支持矩阵保留 |
| 整理数据 | 打开 XLSX/CSV → 改公式 → 筛选汇总 → 存回 XLSX | 公式由内核计算，导出 CSV 时明确提示公式与样式损失 |
| 做汇报 | 打开 PPTX → 改页 → 放映 → 导出 PDF | 放映不是截图轮播；观众屏与演讲者视图分离 |
| 处理 PDF | 打开 PDF → 搜索 → 批注 → 另存 | 输出文件可被独立阅读器打开 |
| 写笔记 | 打开 MD → 源码/预览切换 → 保存 | 未修改时打开/切换视图**不重写原文件**（保留 BOM、换行风格） |
| 离线办公 | 断网状态下打开并编辑 6 类文件 | 全部可用；不弹登录框；不加载 CDN 资源 |

## 4. 功能基线（首版范围）

范围：**核心 6 个模块**。ElyOffice 原 PRD 自身把邮件 / Git / Agent 标注为"第二发布"，
本项目首版同样不含；它们在架构上预留引擎插槽（§3.2 引擎抽象），二期可插入。

### 4.1 模块与格式（调度表来源：`packaging/types.tsv` + 本项目新增行）

| 模块 | 扩展名 | 内核 | 首版承诺 |
| --- | --- | --- | --- |
| 文字 | .docx .odt .doc .rtf | LibreOfficeKit | 原生打开/编辑/保存 |
| 表格 | .xlsx .ods .xls .csv .tsv | LibreOfficeKit | 原生打开/编辑/保存 |
| 演示 | .pptx .odp .ppt | LibreOfficeKit | 原生打开/编辑/保存 + 放映 |
| PDF | .pdf | PDFium（BSD-3）+ lopdf（MIT）写入层 + Tesseract（Apache-2.0）OCR | 阅读 / 搜索 / 批注 / 页面管理 / OCR |
| Markdown | .md .markdown | markdown-rs 解析 | 源码 / 可视 / 预览三模式，保存不回写未改内容 |
| 文本 | **.txt**（本项目新增） | 原生 | 纯文本编辑，按编码探测打开 |

### 4.2 统一外壳（首版必须具备）

| 编号 | 条目 | 完成要求 | 验收 |
| --- | --- | --- | --- |
| SH-01 | 单窗口多标签 | 6 类文档可在同一窗口标签页混排；标签显示名称、类型图标、脏标记 | 截图 + 手工检查 |
| SH-02 | 功能区 | Ribbon 按「开始/插入/布局/视图/审阅/工具」分页签；菜单与功能区同源同语义 | 菜单项与功能区按钮指向同一命令 |
| SH-03 | 开始页 | 新建（按格式）、最近文件、模板入口 | 新建即建空会话，首次保存前无隐含路径 |
| SH-04 | 状态栏 | 显示当前文档状态（未保存/已保存/冲突/只读/外部已修改/保存中） | 对应 `SaveState` 全覆盖 |
| SH-05 | 标签拖拽 | 标签可拖出成独立窗口，也可拖回合并 | 拖出/拖回均不丢文档状态 |
| SH-06 | 工作区 | 可命名保存一组标签并跨重启恢复 | 重启后恢复同一组标签 |
| SH-07 | 统一快捷键语义 | Ctrl 系（非 macOS）；同语义操作键位一致 | 菜单与快捷键结果一致 |
| SH-08 | 中文输入法 | 组合输入、候选框、撤销与焦点切换一致 | 拼音输入 + 中英混排 |

### 4.3 文件、保存与恢复（承接 ElyOffice PRD 的 FILE-01..10，并强制执行）

| 编号 | 条目 | 完成要求 |
| --- | --- | --- |
| FS-01 | 原子保存 | 写临时文件 → 校验写入结果 → 替换目标；失败保留原文件与未保存内容 |
| FS-02 | 外部修改检测 | 保存前检查外部变更；冲突时提供重新加载 / 保留本地副本 / 比较，**不静默覆盖** |
| FS-03 | 修订号 | 保存任务绑定修订号；旧修订保存完成不得把新编辑标为已保存 |
| FS-04 | 恢复副本 | 默认 10 秒一份，保留最近 20 份、最多 7 天；失败时如实显示最后成功时间 |
| FS-05 | 关闭确认 | 保存 / 放弃 / 取消三选一；显式放弃后不误判为崩溃恢复 |
| FS-06 | 路径健壮 | 空格、中文、非 ASCII、超长路径均可用；保留原始大小写 |
| FS-07 | 损坏文件 | 给出可执行提示；PDF 修复副本不覆盖损坏原件 |

### 4.4 Windows 集成

| 编号 | 条目 | 完成要求 |
| --- | --- | --- |
| WIN-01 | 单实例 | 每用户单实例；第二实例经命名管道把路径交给首实例后退出 |
| WIN-02 | 文件关联 | 每格式族一个 ProgID（`MPelyoffice.Document.1` 等）；写 `OpenWithProgids`、`RegisteredApplications`、`ShellNew`；注册后调用 `SHChangeNotify` |
| WIN-03 | 不夺默认 | 任何代码路径都不得写 `UserChoice`；卸载**不删除** `HKCR\.<ext>` 默认值 |
| WIN-04 | 卸载洁净 | 只删除本安装器写入的注册表值与程序目录；**保留用户文档** |
| WIN-05 | 免管理员 | 默认按用户安装到 `%LOCALAPPDATA%\Programs\MPelyoffice`，写 `HKCU\Software\Classes` |
| WIN-06 | 拖放与命令行 | 拖放文件到窗口 → 新标签；`MPelyoffice.exe a.docx b.xlsx` → 两个标签 |

## 5. 明确不做（边界，不是延后清单）

- 邮件客户端、Git 客户端、Agent 会话（二期插槽预留，首版不实现）
- 云同步、多人协同、账号体系、在线文档服务
- VBA / 宏 / ActiveX / COM 插件执行；外部链接自动更新
- 夺取文件默认关联、驱动级外壳扩展、后台常驻服务
- Windows ARM64、移动端、浏览器版

## 6. 运行环境与许可红线

| 项 | 约束 |
| --- | --- |
| 目标系统 | Windows 10 1809+ / Windows 11，x86_64 |
| 安装权限 | 免管理员（per-user）为默认；机器级安装为可选 |
| 第三方许可 | **仅允许 MIT / BSD-2/3 / Apache-2.0 / MPL-2.0**；AGPL、GPL、LGPL、专有商业库一律不得进入分发包 |
| 字体 | **不再分发任何字体**，使用系统字体（含中文），规避字体再分发授权风险 |
| 网络 | 全部功能离线可用；不加载 CDN 脚本/字体/样式 |

## 7. Definition of Done（首版完成判定）

1. §4.2 全部条目通过，§4.3 的 FS-01..07 全部有自动化测试或可复现脚本。
2. 干净虚拟机上安装**单个**包后，§4.1 六类文件均可打开、可编辑、可保存、可重新打开。
3. 全量许可证清单（`docs/mp/06`）与实际分发物逐项对齐，无红线组件。
4. 对抗式审查报告（`docs/mp/08`）中 P0/P1 项全部关闭并留有复验证据。
5. 卸载后系统无残留注册项，用户文档完好。
